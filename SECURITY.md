# Security

MediaHub is a hobby project for use on a home network. It isn't meant to be exposed to the internet.

## Reporting a problem
Please report security problems privately, not in a public issue. Use GitHub's **Report a vulnerability** button on the repository's **Security** tab. Include what you found, how to reproduce it, and the MediaHub version (shown on the **About** page).

This is maintained in spare time, so there's no guaranteed response time, but reports are read and taken seriously.

## Supported versions
Only the latest release gets fixes. Installs update themselves, or you can install the newest release by hand from the Releases page.
